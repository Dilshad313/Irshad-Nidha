# Mohammed Irshad & Nidha Fathima — Wedding Invitation

A standalone, premium Islamic wedding invitation site. Pure HTML, CSS and
vanilla JavaScript — no build step, no backend. Open `index.html` directly
in a browser to view it.

## How to customize

Everything that changes per-wedding lives in one place: the `weddingData`
object at the top of [script.js](script.js).

```js
const weddingData = {
  groom: "Mohammed Irshad",
  bride: "Nidha Fathima",
  groomFather: "...",
  groomMother: "...",
  brideFather: "...",
  brideMother: "...",
  date: "...",          // display text, e.g. "20th December 2026"
  day: "...",           // e.g. "Sunday"
  time: "...",          // e.g. "11:00 AM"
  venue: "...",
  address: "...",
  weddingDateISO: "",   // drives the live countdown, e.g. "2026-12-20T11:00:00"
  googleMapsUrl: ""     // drives the "Get Directions" buttons
};
```

Until `weddingDateISO` and `googleMapsUrl` are filled in, the site shows
honest placeholders ("Date to be announced", disabled direction buttons)
instead of fake data.

Every place a name appears (hero, family cards, intro gate, the two script
"Groom & Bride" headings) sizes itself automatically based on `groom`/`bride`
string length — see `sizeClassForName()` in [script.js](script.js) and the
`.name--long` / `.name--xlong` rules in [style.css](style.css). Longer full
names just render a bit smaller; no manual font-size tuning needed when you
change them.

## Location QR code

The "Scan for Location" card displays [assets/gallery/qr.png](assets/gallery/qr.png)
directly — it is not generated from `googleMapsUrl`, so replace that image
file with a new QR code if the venue changes.

## Background music (optional)

Add a file at `assets/music/music.mp3`. It attempts to autoplay on load;
where the browser blocks that (most mobile browsers, and some desktop ones,
until the visitor interacts), the toggle button in the navigation bar
offers manual play instead. The toggle stays hidden if the file is missing.

## Colors

All colors are CSS variables at the top of [style.css](style.css)
(`:root { --primary-green, --deep-green, --gold, --cream, --text-dark, ... }`,
plus `--fx-*` for the fireworks/confetti palette). The default theme is a
festive wine & rose-gold palette. Change the variables there to retheme
the whole site.

## Celebration effects

Opening the invitation (and the countdown reaching zero) triggers a
fireworks + confetti burst on a full-screen canvas (`#fxCanvas`), and
buttons give a small colored "pop" on tap. All of it is skipped
automatically for visitors with `prefers-reduced-motion` enabled. See
`initCelebration()` and `initPopEffects()` in [script.js](script.js).

## Floral artwork

The hero's central bouquet (`.floral-crest`), its small closing flourish
(`.floral-divider`) and the ambient falling petals (`.petal`) are plain
SVG files in [assets/floral/](assets/floral/) — `crest.svg`, `divider.svg`,
`petal.svg` — referenced from [style.css](style.css), not inlined. They
were generated by a small script (not part of the site) that composes
roses, filler blossoms, leaves and baby's-breath dots from reusable petal
shapes; swap the files for different artwork, or edit the hex colors
inside each SVG to retheme the florals independently of the rest of the
palette.
